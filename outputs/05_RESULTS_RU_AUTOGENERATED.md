# Результаты биологической ветки: автоматически из текущего R-запуска

**Статус:** вычислительная версия для сверки авторами; не окончательная редакция статьи.

## Технический контроль и EMSC

Исследованы 25 спектров детской десневой жидкости, четыре измерения чистого носителя и один архивный носитель. Минимальная корреляция между чистыми носителями составила r = 0.999989; коэффициент вариации интегрального сигнала — 0.819%.

EMSC выполнена с основным шаблоном DPT4 и единым биологическим reference (средний спектр 25 детей). Как проверки чувствительности использованы проекции для DPT4 и архивного носителя с базисом из постоянной, линейной и квадратичной функций. Клинические метки в предобработке не использовались.

## Спектральная вариация после EMSC

В области 1540–1720 см⁻¹ PC1 объясняет 79.32% дисперсии при DPT4; в области 2870–3050 см⁻¹ — 76.53%.

## Ассоциация с документированным пародонтальным статусом

Для C–H-области по основной модели EMSC_DPT4 описательная величина эффекта Cliff's δ = 0.758, точное двустороннее перестановочное p = 0.0357 (3 против 22). При ограничении сравнительной группы шестью детьми 14–17 лет δ = 0.778 и p = 0.0952 (3 против 6).

В белковой области 1540–1720 см⁻¹ соответствующая описательная величина эффекта составила δ = -0.121 (точное p = 0.7826); при возрастном сравнении δ = -0.444 (p = 0.3810).

Для C–H-области косинус направления группового спектрального контраста при полной и возрастной сравнительных группах составил 0.972. При исключении по одному случаю минимум составил 0.928. Контраст по EMSC_DPT4 был согласован с альтернативной проекционной коррекцией для архивного носителя (косинус 0.962).

При пассивной проекции четырёх независимых спектральных референсов в детское CH-PC1 пространство (EMSC с DPT4) образец G с документированным гингивитом получил координату 0.714 SD; три контрольных образца N имели координаты в интервале от -2.740 до -0.249 SD. Это качественное дополнительное наблюдение, а не внешняя диагностическая валидация.

При этом корреляция индивидуальных координат CH-PC1 основной EMSC и архивной проекционной модели равна 0.932; устойчивость формы группового контраста не означает тождественность индивидуальных PCA-координат.

## Биологическая интерпретация

Результаты согласуются с наличием групповой вариации формы C–H-ассоциированных полос десневой жидкости, сопутствующей документированному состоянию пародонта. Эти полосы включают колебания C–H-связей, встречающихся в липидных и белковых структурах. Спектральный контраст сам по себе не идентифицирует конкретное вещество, его концентрацию или механизм воспаления.

Из-за трёх случаев с документированной патологией, ассоциации пародонтального статуса с другими клиническими характеристиками и поискового характера сравнений нельзя заявлять диагностическую точность, специфичность или причинную связь. Приведённые p не скорректированы за множественные сравнения.

## NMF как независимая проверка разложения спектра

Для новой NMF, построенной непосредственно из GCF_MASTER_34.csv с единым положительным сдвигом, фиксированными спектром носителя и постоянным базисом, ошибка реконструкции равнялась 14.536% при K=0 и 4.500% при K=2.

Эта NMF имеет иное входное преобразование, чем ранее сохранённая NMF из active_absorbance.csv; прямое сопоставление ошибок двух вариантов некорректно. Свободные компоненты не приравниваются к отдельным биохимическим веществам.

## Воспроизводимость

Все приведённые числа, групповые медианы, нагрузки и кривые построены из одной 34×793 матрицы при явных параметрах EMSC и фиксированных спектральных окнах. R-версия и вычислительный протокол сохраняются вместе с результатами.
