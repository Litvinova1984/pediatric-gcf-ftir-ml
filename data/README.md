# Подготовленная спектральная матрица / Prepared absorbance matrix

`public/GCF_MASTER_34_PUBLIC.csv` — минимизированный аналитический вход для воспроизведения этой статьи: **34 строки × 793 спектральных признака**. Это НЕ исходные файлы прибора и НЕ SNV-нормализованная педиатрическая матрица из статьи Data.

Строки: 25 индивидуальных педиатрических спектров, 3 независимых спектра образцов, обозначенных врачами как норма, 1 обозначенный как гингивит, 4 чистых бумажных носителя и 1 архивный носитель. Порядок строк сохраняется относительно исходного фиксированного анализа, чтобы результаты алгоритмов, использующих фиксированные начальные состояния, оставались воспроизводимыми.

В CSV оставлены только `sample_id` (заменённые коды детей без таблицы соответствия), `sample_group`, `age_14_17` (булев признак 14–17 лет), `periodontal_status` (две аналитические категории) и 793 переменные `wn_...` (волновые числа, см⁻¹). Пустые возрастные и пародонтальные поля для внешних и технических образцов не означают медицинскую норму. Удалены исходные имена файлов, точные возрасты, пол, пубертатный, эндокринный и НДСТ-статус.

**Внимание.** Сами индивидуальные спектры позволяют проводить сопоставления с ранее опубликованными наборами, поэтому новые псевдонимы не гарантируют анонимность. Публикация индивидуальных значений `periodontal_status` и `age_14_17` должна входить в разрешённый объём раскрытия клинических данных; эта кандидатная сборка не заменяет этического согласования.

`data/private/` остаётся локальной исключённой из Git папкой, если исследователи предпочитают собственный разрешённый исходный ввод. При наличии обоих файлов код отдаёт приоритет `data/public/`.
