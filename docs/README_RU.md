# Как воспроизвести анализ

Репозиторий содержит готовую аналитическую матрицу **34 × 793** спектральных признака. Это подготовленные значения поглощения, а не исходные файлы `.spc`/`.dpt` и не SNV-матрица из статьи в *Data*.

Анализ: контроль четырёх чистых носителей → EMSC с DPT4 → PCA по областям 1540–1720 и 2870–3050 см⁻¹ → точные перестановочные тесты, величины эффекта и проверки устойчивости → NMF с фиксированным компонентом носителя → два публикационных рисунка.

## Запуск

В RStudio выберите команду `source(file.choose(), encoding = "UTF-8")`, затем файл **`run_all.R` в корне**. После завершения аналогично запустите **`verify_local_results.R`**. Либо из терминала, открытого в корне репозитория:

```bash
Rscript run_all.R
Rscript verify_local_results.R
```

Расчёты сохраняются в `R/results/`. **Эту папку не загружать на GitHub:** в ней могут быть индивидуальные коэффициенты, координаты и другие производные данные. В репозитории для открытого доступа уже сохранены только согласованные сводные таблицы (`outputs/`) и два рисунка (`figures/`). Для построения PNG дополнительные R-пакеты не требуются. При отсутствии XQuartz/Cairo на Mac необязательные PDF пропускаются.

## Статус проверки

На Mac mini был выполнен анализ подготовленного входа, оба рисунка заново созданы в папке этого репозитория; после исправления путей пользователь получил сообщение **`PASS: 5/5 numeric checks, NMF summary present, 2 final PNG present`**. Однокомандный запуск `Rscript run_all.R` в отдельно распакованном релизе дополнительно не испытывался. Сведения об исходных численных контрольных точках находятся в `checks/`; подробности — в `docs/VERIFICATION.md`.

**Предел воспроизводимости:** только от обработанной матрицы. Преобразование первичных файлов прибора в аналитический вход не включено. Публикация индивидуальных спектров вместе с метками состояния пародонта и возрастной группы требует подтверждения разрешённого объёма раскрытия клинической информации, независимо от прежней публикации SNV-матрицы в *Data*.
